2 Qué es SysAlquileres

Problema

Datos dispersos

Cuadernos o Excel permitían alquilar dos veces un departamento, registrar pagos sin contrato o duplicar inquilinos.

Solución

Sistema centralizado

Cuatro módulos CRUD con validaciones reales antes de guardar.

Innovación

Nota de venta

Impresión térmica 58/80 mm por cable o Bluetooth y APK informativa con roles.

4 Flujo de una operación

Ejemplo: registrar un pago.

  1. Botón Guardar dispara onGuardar() en el controller.
  2. El controller construye el objeto Pago con los campos del formulario.
  3. PagoServiceImp valida con Validador.validar().
  4. PagoRepository arma un INSERT ... VALUES (?, ?, ...).
  5. HikariCP presta una conexión y Supabase ejecuta la sentencia.
  6. La tabla se actualiza con la ObservableList.
IPagoService.save(pago) → Validador.validar(pago) → PagoRepository.insert(...)

5 Reglas de negocio

Usuarios

Solo activos; usuario único.

Departamentos

Número único; no borrar con contratos.

Inquilinos

DNI único de 8 dígitos; RUC de 10–11.

Contratos

Fecha fin > inicio y sin solape vigente.

Estados

Ocupado al crear, disponible al finalizar.

Pagos

Monto > 0; descuento e IGV ≥ 0.

Regla estrella findVigenteSuperpuesto(idDepto, inicio, fin, excluirId) lanza BusinessException si el departamento ya tiene contrato vigente en esas fechas.

6 Base de datos y Supabase

Estado actual Se está usando Supabase / PostgreSQL, porque las variables SUPABASE_DB_* están configuradas y tienen prioridad sobre el H2 de application.properties.
Frase para el docente “Para la exposición entregamos H2 local: es gratuita, se crea sola y hace que cada estación funcione sin internet. Para un software comercial se migraría a una única base PostgreSQL en la nube con secretos gestionados, autenticación real y copias de seguridad; ese servicio tiene un costo adicional. La arquitectura por capas permite cambiar de base sin tocar la interfaz.”

7 APK y roles (apoyo informativo)

👤 ADMIN

Listados generales de los 4 módulos, solo lectura.

🏠 CLIENTE

Solo su departamento, contrato, vencimiento e historial de pagos.

  1. Al crear contrato en el escritorio se genera usuario = DNI y clave aleatoria de 8 caracteres.
  2. El administrador ve esas credenciales en un diálogo y se las entrega al inquilino.
  3. La APK valida el rol desde /rest/v1/usuario y enruta a la pantalla correspondiente.
  4. Si el cliente olvida la clave, el panel Accesos clientes la muestra o genera una nueva por JDBC.
Sin secret key No hace falta la llave secreta de Supabase: el escritorio edita la tabla usuario con las variables SUPABASE_DB_*. El panel es un CRUD completo (alta, consulta, clave, activar/desactivar y eliminar) y la clave se desactiva al finalizar contrato y se reactiva al crear uno nuevo.

9 Guion de 12 minutos

  1. 0–1 min: Presentación. “Sistema de escritorio para administrar alquileres…”
  2. 1–2 min: Problema: doble alquiler, pagos sin contrato, fechas imposibles.
  3. 2–4 min: Arquitectura por capas y AppContext. Mostrar el diagrama.
  4. 4–6 min: Módulos. Departamentos → Inquilinos → Contratos → Pagos.
  5. 6–7 min: Regla del solapamiento y estados automáticos.
  6. 7–8 min: Base: Supabase activo, variables de entorno, HikariCP y SSL.
  7. 8–10 min: Demo: pago nuevo → nota → cambiar a 80 mm → imprimir.
  8. 10–11 min: APK con roles y recuperación de clave desde Accesos clientes.
  9. 11–12 min: Conclusión y preguntas.

10 Preguntas probables

¿Por qué App no extiende Application directamente?

Para evitar “JavaFX runtime components are missing” desde el botón Run. El main está en App y la ventana en App.Ventana.

¿Por qué capas?

Separación de responsabilidades: cambiar la base no afecta la vista; cambiar una regla no afecta los botones.

¿Se está usando H2 o Supabase?

Supabase, por las variables SUPABASE_DB_* que tienen prioridad. H2 es el valor por defecto del properties.

¿Por qué BigDecimal y no double?

Porque el dinero no puede perder centavos por redondeo binario.

¿Cómo imprime Bluetooth?

Si Windows lo instala como impresora, modo Windows; si solo crea puerto COM, se envían comandos ESC/POS por jSerialComm.

¿Cómo recupera la clave un cliente?

Desde Accesos clientes en el escritorio: se ve, se genera una nueva y se guarda, sin secret key.

¿La nota de venta es fiscal?

No. No reemplaza comprobantes de SUNAT.
