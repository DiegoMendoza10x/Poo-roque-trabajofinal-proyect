1 Ejecutable de Windows

Se genera una imagen de aplicación con jpackage: incluye Java y JavaFX, así que la PC destino no necesita JDK.

powershell -ExecutionPolicy Bypass -File scripts\build-exe.ps1

# Resultado
dist\SysAlquileres\SysAlquileres.exe
Ojo El .exe necesita las carpetas app\ y runtime\ a su lado. Por eso se entrega el ZIP.

2 ZIP portable

Contenido

app/, runtime/ y SysAlquileres.exe.

Tamaño

Aproximadamente 60 MB.

Uso

Extraer y ejecutar el .exe; no es instalador.

Para generar un instalador .exe o .msi haría falta WiX Toolset 3.x.

3 APK informativa v1.1

cd android
$env:JAVA_HOME="C:\Program Files\Java\jdk-17"   # GraalVM 21 falla en jlink
.\gradlew.bat assembleRelease

# Salida
android\app\build\outputs\apk\release\app-release.apk
# Entregable
dist\SysAlquileres-Movil-v1.1.apk
  • Login con rol ADMIN o CLIENTE.
  • Cliente ve solo su departamento y pagos.
  • Solo lectura: no crea ni edita datos.
adb install -r "dist\SysAlquileres-Movil-v1.1.apk"

5 Preguntas frecuentes

¿El .exe necesita Java instalado?

No. El runtime se incluye dentro del ZIP portable.

¿Por qué no usar GraalVM 21 para la APK?

Gradle 8.11 falla al transformar el módulo JDK con jlink. Se usa JDK 17.

¿La APK imprime?

Comparte el ticket por Android; la impresión térmica directa está en el escritorio.
