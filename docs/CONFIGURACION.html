3 Base activa

Este entorno Supabase / PostgreSQL, por las variables SUPABASE_DB_*.
H2 inicial vs nube La versión entregada arranca con H2 embebida: gratuita, automática y sin internet. La base en la nube (Supabase) es opcional, permite compartir datos y tiene un costo adicional de hosting; requiere configurar variables de entorno.
  1. application.properties trae H2 por defecto.
  2. Propiedades -Ddb.url=....
  3. Variables DB_*.
  4. Variables SUPABASE_DB_* (prioridad máxima).
SUPABASE_DB_URL=jdbc:postgresql://aws-0-us-east-1.pooler.supabase.com:5432/postgres
SUPABASE_DDL_AUTO=false
SUPABASE_SEED_DEMO=false

La URL se ajusta con sslmode=require y prepareThreshold=0. Para volver a H2: cerrar la app, quitar esas variables y ejecutar de nuevo.

5 Accesos clientes

Panel Accesos clientes en la barra lateral (CRUD completo):

  • Nuevo cliente: alta manual por DNI, nombre y clave.
  • Lista usuarios CLIENTE con DNI, nombre, rol, estado y clave.
  • Generar/Guardar clave, Eliminar con confirmación, Activar y Desactivar.
  • No necesita la secret key de Supabase: edita usuario por JDBC.
Automático Al finalizar un contrato la clave se desactiva; al crear uno nuevo se reactiva.
Académico La clave se guarda en texto plano. En producción se usaría hash + restablecimiento por correo.

6 Prueba rápida

  1. Entrar con admin / admin123.
  2. Abrir Config. impresión y verificar motor y ruta del archivo.
  3. Imprimir prueba en POS-58-Series.
  4. Abrir Accesos clientes y ver un usuario.
  5. Cambiar papel a 80 mm y abrir una nota de venta.
