1 Configuración

application.properties trae H2 por defecto, pero las variables de entorno lo sobrescriben.

H2 inicial vs nube H2 embebida es gratuita y se crea sola; es la base incluida para la exposición. Supabase/PostgreSQL es la opción en la nube para compartir datos y tiene un costo adicional de hosting. La arquitectura por capas permite cambiar de una a otra sin modificar la interfaz.

3 SSL y prepareThreshold

sslmode=require

Cifra la conexión para proteger credenciales y datos en internet.

prepareThreshold=0

El pooler en modo transacción no admite sentencias preparadas con nombre; evita el error prepared statement already exists.

El código los agrega automáticamente en normalizarUrl().
