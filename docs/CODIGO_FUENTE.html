2 Paquetes y responsabilidades

PaqueteResponsabilidad
controllerEventos de FXML, formulas y tablas.
serviceValidaciones y reglas de negocio.
repositorySQL parametrizado y mapeo a objetos.
modelDatos con Lombok (@Data, @Builder).
configDI, conexión y configuración persistente.
impresionTicket 58/80 mm y drivers.
componentsDiálogos, chips y vista de impresión.
Regla de oro El controller no tiene SQL y el repository no decide reglas.

3 Clases clave

App.java

Contiene el main; la ventana está en App.Ventana para evitar el error de JavaFX en el IDE.

AppContext

Singleton que arma repositorios → servicios → controladores.

DatabaseConfig

Lee properties y variables de entorno, configura HikariCP y normaliza la URL.

NotaVenta

Genera el ticket en 32 o 48 columnas según el papel.

ConfigImpresion

Guarda papel, conexión, puerto y baudios en el perfil del usuario.

UsuarioController

Panel de accesos: ver y renovar claves de clientes.

4 Compilar y ejecutar

cd "D:\CRUD DEPARTAMENTOS\SysAlquileres"
mvn javafx:run
mvn -B -DskipTests package

# APK (JDK 17: Gradle 8.11 falla con GraalVM 21)
cd android
$env:JAVA_HOME="C:\Program Files\Java\jdk-17"
.\gradlew.bat assembleRelease
Login de prueba admin / admin123. Si usas Supabase, las credenciales se leen de variables de entorno.

5 Dependencias principales

LibreríaUso
JavaFX 21Interfaz y FXML.
H2 / PostgreSQLBase local y remota.
HikariCPPool de conexiones.
Jakarta ValidationAnotaciones y validación.
LombokReduce getters/setters.
jSerialCommPuerto COM para Bluetooth.
SLF4J + LogbackLogs.
Base incluida H2 va incluida y es gratuita: se crea sola y no necesita internet. PostgreSQL/Supabase es la opción remota para compartir datos y tiene un costo adicional de hosting.

6 Convenciones

  • Dinero siempre con BigDecimal.
  • Fechas con LocalDate / LocalDateTime.
  • Consultas con ?: nunca concatenar valores.
  • Errores de negocio con BusinessException y mensaje en pantalla.
  • Estilos reutilizables en app.css (card, badge, boton-primario).
